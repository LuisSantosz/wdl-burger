WDL BURGER — CARDÁPIO PREMIUM

Arquivos:
- index.html
- style.css
- script.js

COMO USAR
1. Abra a pasta no VSCode.
2. Abra o index.html com Live Server.
3. No arquivo script.js, procure por:
   const whatsappNumber = '5511999999999';
   e substitua pelo WhatsApp oficial da WDL BURGER, com DDI + DDD + número, apenas números.

COMO TROCAR PRODUTOS
No topo do script.js existe a constante "products".
Edite:
- name: nome do item
- price: preço
- desc: descrição
- image: URL da imagem
- category: burgers, combos, porcoes ou bebidas
- tag: selo do produto

OBSERVAÇÃO
As fotos atuais são carregadas da internet. Para produção, recomenda-se baixar as fotos próprias da lanchonete e apontar o campo image para arquivos locais.
